# fullStackProject

## Run the RSVP app

Open a terminal in the project folder and run:

```sh
cd /workspaces/fullStackProject
npm run dev
```

Open the local URL printed by Vite in your browser. You only need to install dependencies once (or again after they change):

```sh
npm install --prefix client
```

The RSVP app runs in the client; the server package does not currently provide an application start command.
